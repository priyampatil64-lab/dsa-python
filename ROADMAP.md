# 30-Day DSA Roadmap

A day-by-day plan to work through the *Most Asked Coding Interview Questions* guide (190 problems, 10 topics) in 30 days, at roughly 6-7 problems/day. Each day's problems come directly from the guide, grouped by topic so concepts build on each other.

**How to use this:**
1. Each day, open the listed problems on LeetCode and attempt them yourself first.
2. Solve in Python3.
3. Once accepted, save your solution + notes in a `dayXX_topic` folder in this repo (see `day01_arrays_pt1` as the template once created).
4. Check off the day below as you complete it.
