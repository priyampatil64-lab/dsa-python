## Problems

### 1. Two Sum ✅
**Link:** https://leetcode.com/problems/two-sum/
**Difficulty:** Easy

**Approach:** Store each visited value with its index in a hash map (`seen`). For every element, check whether its complement (`target - num`) already exists in the map before inserting the current value. This avoids the O(n²) brute-force nested loop.

**Complexity:** Time O(n) | Space O(n)

**File:** `two_sum.py`
